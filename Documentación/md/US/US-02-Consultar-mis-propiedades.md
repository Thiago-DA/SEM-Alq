| **Consultar mis propiedades** |
| - |
| Como locador, quiero consultar mis propiedades, para saber rápidamente cuáles se encuentran publicadas o alquiladas y el estado de alquiler de las mismas. |
| **Criterios de aceptación:** |
| - Se debe haber iniciado sesión. |
| - Se deben ver todas las propiedades registradas por el locador, alquiladas o no, publicadas o no. |
| - Se debe mostrar la imagen principal de cada propiedad visible. |
| - Se debe debe mostrar la dirección de cada propiedad visible. |
| - Se debe mostrar el estado actual de la publicación: publicada, pausada, alquilada, alquilada/publicada. |
| - Se debe mostrar el nombre del locatario para propiedades alquiladas. |
| - Se debe mostrar el estado del alquiler para propiedades alquiladas: al día, con pago pendiente, retrasada. |
| - Se debe mostrar si las propiedades poseen reclamos no resueltos. |
| - Se debe mostrar la fecha del próximo ajuste y el tipo de ajuste. |
| - Se pueden filtrar las propiedades por barrio, tipo, estado de publicación, si posee reclamos. |
| - Al filtrar por barrio, solo se deben poder seleccionar barrios que coincidan con las propiedades del locador. |
| **Pruebas de usuario:** |
| - Probar consultar mis propiedades sin tener propiedades registradas (pasa). |
| - Probar consultar mis propiedades y filtrar por su estado de publicación actual (pasa). |
| - Probar consultar mis propiedades y filtrar por su estado tipo (pasa). |
| - Probar consultar mis propiedades y filtrar por reclamos y solo se muestran las propiedades con reclamos (pasa). |
| - Probar consultar mis propiedades y filtrar por reclamos y no hay propiedades con reclamos (pasa). |
| - Probar consultar mis propiedades y al filtrar solo se pueden elegir los barrios de mis propiedades (pasa). |
