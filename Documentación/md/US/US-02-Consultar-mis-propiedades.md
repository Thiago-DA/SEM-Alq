| **Consultar mis propiedades** |
| - |
| Como locador, quiero consultar mis propiedades, para saber rápidamente cuáles se encuentran publicadas o alquiladas y el estado de alquiler de las mismas. |
| **Criterios de aceptación:** |
| - Se debe haber iniciado sesión. |
| - Se deben ver todas las propiedades registradas por el locador, alquiladas o no, publicadas o no. |
| - Se debe mostrar la imagen principal de cada propiedad visible. |
| - Se debe debe mostrar el título de cada propiedad visible. |
| - Se debe mostrar el estado actual de la propiedad: publicada, no publicada, alquilada. |
| - Se debe mostrar el nombre del locatario para propiedades alquiladas. |
| - Se debe mostrar el estado de la propiedad para propiedades alquiladas: al día, con pago pendiente, retrasada. |
| **Pruebas de usuario:** |
| - Probar consultar mis propiedades sin tener propiedades registradas (pasa). |
